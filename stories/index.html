Contributor Relay in practice

Contributor Stories

Hive turns first contribution into a minutes-long path: sign in, pick a task, let the relay and your agent scaffold the work, then learn the codebase by reviewing and merging real pull requests.

How it works in 5 minutes

From sign-in to reviewed code

The relay is documented as a contributor-owned process that connects over WebSocket, receives one task at a time, drives the selected local CLI, and reports completion or PR metadata back to the hive.

  1. Sign in at a hive contributor portalEach hive serves /contribute with live queue stats and setup commands.
  2. Pick eligible work from the queueThe hub applies repository, label, assignment, dependency, cooldown, and trust-tier gates before work is offered.
  3. Run the relay with your CLIjust contribute-hive starts the relay and agent locally or in the reference container path.
  4. Review, submit, and merge through project rulesThe hub injects short-lived GitHub credentials, receives PR metadata, and keeps the normal maintainer review path.
